# 组局成功概率与摇人推荐（2026-10-27，v4）

## 业务口径

- 个人“到场概率”是在当天能组起球局时，此人实际出勤的估计。不是剩余时间内自行报名的概率，也不是邀请后答应率；系统没有完整邀约/拒绝记录。
- 今天预测北京时间20:00前最终稳定人数至少6人（含随行人员）的概率。19:00为活动开始时间。截止后不再预测新增报名，不足6人为0%；达到11人视为稳定成局；6–10人仍结算有证据的大局偏好退出风险。
- “10人以上”统一指至少11人。随行人员计人数，但不替归属人形成本人出勤、接龙或朋友关系。
- 明天从空接龙开始。只有今天模拟成局且本人出席，才消耗其明天的体力和本周剩余局数；周一重置周局数。

## 统一证据层

成员统计 v5 的 predictionFeatures 同时用于标签和模型的习惯资格：星期/每周局数/大局需近30天至少2次本人记录；近期常打需进入15天榜且至少2个出勤日期。历史习惯是软信号，不是禁令。明确填写的日期/星期不打规则对未报名候选仍是硬约束。

个人与成局模型共用 attendanceBaseline：

1. 只把目标日期以前实际成局的日期作为个人出勤机会；同日多场合并，本人任一场实际出席计一次。无球局、入群前和只替随行人员报名均不算本人缺席/出勤。
2. 30天半衰期；总体率向有真实接龙证据成员的群体率收缩6个伪样本，同星期率再向个人总体率收缩6个伪样本。已确认的节假日、调休日和未知日历年份不参与普通星期条件化。
3. 与已收缩的真实接龙参与画像融合，两类重叠频率证据不重复相乘；旧“近期常打”额外加分和“从未在周X打过”固定四分之一惩罚取消，频率/星期信息只在基线进入一次。
4. 成局模型使用该基线相对群体先验的对数几率（限制在±2.5）表示成员差异；个人概率不乘群体成局截距或剩余时间暴露。
5. 每周观察上限达到后，使用有界软惩罚：对数几率调整为 -1.2 × n/(n+6)，n为近30天本人场次，且必须属于有效周局数名单。明天本周最后一次额度被今天消耗时使用相同惩罚。

## 拍档与水平因素

- 只读取有效最佳拍档名单。普通同场频次和未入名单的历史方向性关系不再暗中加分；日历回退也不进入模型。
- 自动关系按校正方向差值和证据可靠度计算有界几率提升；手工关系无充足证据时采用保守1.25倍几率先验，不是到场率乘1.25。
- 同一直接关系的历史证据与真实接龙方向画像采用融合，不重复加分。最强已接龙朋友贡献完整影响，其他朋友仅贡献35%，总几率提升最多2倍。人工展示排名不参与计算。
- 当前有低等级本人报名时，同等级范围匹配仅为1.1倍几率的弱信号。
- 朋友共同参与使用直接边的 Gaussian copula：每条关系共享一个独立扰动，每人总共享方差不超过0.35。它保持各人的边际概率并引入保守相关性；A—B和B—C不创建A—C关系。相关性是模型先验，不声称已证实因果带动。

## 体力、人数及随行

- 没有连打记录不再等于只能打一天。体力判断需要“前一天本人参加，而且后一天确有球局”的可比较机会；近60天条件出勤率向本人基线收缩6个机会，再转换为有界几率因子。无机会不凭空施加80%降幅。
- 两/三天能力名单可避免对应静态能力惩罚。真实接龙体力画像与订场证据按对数尺度融合，画像时效仅衰减一次。
- 已明确报名的体力留存惩罚较弱，使用证据体力因子的平方根，不再一律55%。
- 大局偏好仅对当前有效统计名单生效，并按历史样本强度与可靠学习信号收缩；个人概率采用历史成局规模估计达到11人的机会，不使用剩余时间衰减的全群模拟反压个人数值。
- 订场记录已是最终出勤，个人模型不再重复乘普通95%留存；仅调整相对退出风险。成局模拟保留已报名者留存、未知成员和随行人数分布，随行与归属人的稳定性相关。

## 整体模拟与性能

空接龙基线仍基于真实成局日和明确结算接龙；没有订场记录的日期采用5%软成功标签而不声称是已观察失败。星期基线向整体收缩10个伪样本。Monte Carlo 校准整体截距并模拟加入、留存、人数门槛及次日体力。

每次模拟使用固定的成员/归属人随机子流，保持同状态可复现，并减少“多加一个成员”引起的随机抽样差异。拍档网络按成员ID规范排序，人工上下移动不改变数值。

摇人固定按到场概率排序，手动置底优先。UI使用 includeCounterfactuals:false，跳过未展示的逐候选反事实模拟，rankingMode=attendanceProbability。引擎仍可按需计算成局提升，作为单独的概率点差，不能当作到场概率。数字最多一位小数；非零不足0.1%如实显示，不添加虚假最低值。

## 学习、同步和验证

- 管理版对真实用户接龙变动保存去重结构化快照；试算、GitHub只读、本地自动填充不写学习数据。只保存ID、随行归属、约束和模型输出，不保存剪贴板原文。
- 每天北京时间12:05重建最近365天的真实证据；00:05刷新统计和节假日日历。手工刷新延续先结算、再训练、重算、读取最新bootstrap的流程。历史修改继续重算结果。
- 学习数据若生成时间晚于预测时点则不使用；手工拍档按创建/删除时间截断。刷新、名单或规则变更会失效对应缓存，单纯调整拍档展示排名不会触发概率重算。
- scripts/verify-partner-management.js 覆盖SQLite持久化/CAS冲突、删除不复活、恢复、多对不传递、只读、未来信息隔离、排名不改概率与朋友标签一致性。
- scripts/backtest-group-probability.js 进行滚动时间回测，逐日只用当时可见记录重建画像；个人仅在真实成局日评分，成局失败仅采用明确结算标签，绝不把无记录直接当失败。输出Brier分数和对数损失，以及样本选择限制。小样本改进不代表邀约概率已校准。
