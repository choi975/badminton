# 订场预估模型

订场预估模型 v4 会随着 Cloudflare D1 中的订场记录自动重新训练。场地和用球分别训练，记录异常时可以只保存而不让该场进入训练样本。

## 场地

```text
场地数 = max(1, ceil(总人次 / 每片场地人数))
```

训练会在 6 到 9 人、步长 0.25 的候选容量中选择历史误差最低的容量。

## 用球

每种球都有独立权重，不把新球型号折算成亚3记录：

```text
加权用球需求 = 总人次 * 每人加权耗球量 + 风险缓冲
某型号推荐数量 = max(1, ceil(加权用球需求 / 该型号权重))
```

亚3作为参考型号权重为 1。其他型号从包含该型号的历史记录中独立学习；没有样本时使用已学习型号的稳健先验估计，仍会显示在高级模型面板中。球型号的价格保存在 `shuttle_types`，多型号记录按每一行的 `type` 分别训练。

## 异常记录

实际场地数与当前预测相差超过 1 个，或实际用球数与当前对应型号预测相差超过 2 颗时，记录界面会询问：

- 仅记录数据，不用于训练预估公式
- 记录并训练预估公式

选择前者时，场地和用球训练标记都会关闭；选择后者时都会进入训练。编辑旧记录也可以通过训练标记重新训练。

## 管理员操作

新增球型号和价格只能从 Cloudflare 管理版的“接龙助手 → 人数统计 → 高级”面板操作。GitHub Pages 备用版保持只读，不显示写入控件。

每次保存订场记录后，Worker 会根据训练标记从 D1 即时重训并返回最新模型；发布脚本会将同一模型同步到 GitHub 和 Worker 的静态快照。
