# 订场预估模型

订场预估模型 v5 会随着 Cloudflare D1 中的订场记录自动重新训练。场地和每个球型号分别训练，记录异常时可以只保存而不让该场进入训练样本。

## 参与者数据

用球模型使用每位实际参与者的成员 ID、性别和等级快照。登记成员可以跨场学习个人差异；没有稳定成员 ID 的随行人员只使用自己的性别和等级，不能继承归属人的个人参数。

旧聚合记录中的 `slots > 1` 只把确实出席的一位已登记成员识别为本人，其余人次按性别、等级和身份均不详处理。`+N` 中的 N 是随行人员编号，不是一次增加 N 人。逐人快照功能上线前的迁移回填数据会永久标记为“不可靠画像”：成员 ID 仍可用于个人层，但性别和等级按不详训练。这个来源标记会在编辑时原样保留；以后补录旧日期的新记录仍按真实录入快照处理，不依赖活动日期猜测。

## 场地

```text
场地数 = max(1, ceil(总人次 / 每片场地人数))
```

训练会在 6 到 9 人、步长 0.25 的候选容量中选择历史平均绝对误差最低、均方根误差次低的容量。

## 用球

每个球型号拥有完全独立的参数集，不设参考型号，也不在型号之间使用耐打倍数：

```text
某参与者对型号 t 的耗球率
  = 型号 t 基准率
  × exp(型号 t × 性别修正
      + 型号 t × 性别等级修正
      + 型号 t × 成员修正)

型号 t 的基础预计量
  = 当前名单内所有参与者耗球率之和

型号 t 的风险缓冲
  = 风险系数 × sqrt(max(基础预计量, 1))

型号 t 的推荐数量
  = max(1, ceil(基础预计量 + 风险缓冲))
```

所有修正值都只从包含该型号的有效订场记录学习。因此同一成员可以对亚3表现为高耗球倾向、对 AS05 表现为低耗球倾向，反之亦然。

性别、性别等级和成员参数采用正值 Poisson 模型与分层 L2 正则化。成员层收缩最强，性别等级层次之；成员至少出现 3 场、性别等级组合至少出现 2 场才建立对应参数。

训练会把“只看人数的基础模型”和多组分层正则强度一起放入按日期留出的最近数据中比较。分层模型必须让平均绝对误差至少改善 0.25 颗且均方根误差不变差才会启用，否则继续使用更稳健的基础模型。该选择会在每次重训时自动重做。

风险系数来自标准化残差的 70% 分位，并用 5 个伪样本收缩且限制极端上限，避免单个异常场次让推荐数量跳变。缓冲按预计量平方根增长，不会给 1 人和 20 人名单机械地加同样数量。

每个型号至少需要 5 场旧数据和 3 场留出数据，才允许选择分层模型；此前只更新该型号自己的基础率。完全没有样本时以每人 0.81 颗的中性冷启动值开始。每个型号最多使用最近 120 个单型号场次，使模型能适应近期打法并保证在线重训成本有上限。达到条件后会自行比较并切换，不需要修改公式或重新人工推导。

## 单型号和混用记录

只有整场使用单一型号的记录，才能回答“当前名单如果使用这个型号会消耗多少”，因此会进入该型号的完整训练。

混用记录只说明当场各型号实际用了多少，无法知道每种球分别覆盖了哪些对局或参与者。v5 会记录这类样本的数量但不把它们强行换算成任一型号的完整耗球标签。未使用某型号的场次也不会被当作该型号耗球量为零。

## 自动重训

新增、编辑或删除订场记录，以及登记新球型号后，Worker 会立即用 D1 中有效记录重训。数据库触发器会为所有训练数据变化递增 revision；模型读取时会同时校验版本、逐型号结构和 revision。即使一次重训中断，下次读取也会发现陈旧模型并自动补训。

离线发布训练器与 Worker 使用相同的参与者展开规则。发布脚本会把最新模型同步到 GitHub Pages 快照和 Worker 静态备用数据。

## 异常记录

实际场地数与当前预测相差超过 1 个，或单型号记录的实际用球数与该型号预测相差达到或超过 2 颗时，记录界面会询问：

- 仅记录数据，不用于训练预估公式
- 记录并训练预估公式

混用记录没有可比较的单型号完整预测，因此不参与用球异常判断；场地异常仍正常判断。

新记录保存前还会要求确认球数是赛后实际用量。确认状态使用独立的 `actualShuttleConfirmed` 字段保存；未确认时仍保存订场和场地数据，但不会让模型把自己预填的预测值再次当作真实标签学习。混用场确认后会保留为可信原始数据并计入“混用排除”统计，只是不进入当前单型号公式。编辑旧记录会原样保留确认状态、训练标记和当时的参与者快照。

## 管理员操作

新增球型号和价格只能从 Cloudflare 管理版的“接龙助手 → 人数统计 → 高级”面板操作。GitHub Pages 备用版保持只读，不显示写入控件。
